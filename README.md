# WB Card Funnel Design Skill

Навык для исследования конкурентов Wildberries, проектирования контентной воронки и подготовки проверяемой инфографики карточки товара.

## Что умеет

- проверяет точный SKU и подтверждённые характеристики;
- показывает shortlist конкурентов и ждёт явного одобрения пользователя;
- разбирает полную галерею каждого одобренного конкурента;
- строит неповторяющуюся последовательность кадров по вопросам покупателя;
- блокирует неподтверждённые claims, подмену товара и неполный research-gate;
- проверяет медиа, OCR и готовность выдачи локальными Python-валидаторами.

## Установка для Codex

```bash
git clone https://github.com/viteab-source/wb-card-funnel-design-skill.git
mkdir -p ~/.codex/skills
cp -R wb-card-funnel-design-skill/wb-card-funnel-design ~/.codex/skills/
```

Перезапустите Codex и попросите применить `wb-card-funnel-design` к фотографиям одного товара.

## Требования

- Codex с доступом к локальным файлам;
- Python 3 для встроенных проверок;
- браузер или другой разрешённый источник для исследования актуальных карточек;
- генератор изображений или графический редактор, если нужны готовые визуалы;
- `MPSTATS_TOKEN` опционален и читается только из окружения.

## Проверка

```bash
python3 -m unittest discover -s wb-card-funnel-design/scripts -p 'test_*.py'
python3 /path/to/skill-creator/scripts/quick_validate.py wb-card-funnel-design
```

## Ограничения публичного пакета

Пакет не содержит фотографии конкурентов, пользовательские исходники, токены, рабочие артефакты и внутреннюю библиотеку вкуса. Они создаются локально у каждого тестировщика. Навык не публикует карточки и не меняет данные Wildberries.

## Обратная связь тестировщика

Укажите товар, входные материалы, найденный shortlist, решение по конкурентам, получившуюся воронку, ошибки валидаторов и 2–3 скриншота результата. Не прикладывайте ключи, cookies и выгрузки кабинета с чувствительными данными.

## Лицензия

До выбора постоянной лицензии разрешено использовать этот release candidate только для тестирования и обратной связи.
