# Bundled fonts

The package includes the Inter variable upright and italic fonts from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/inter
- license: SIL Open Font License 1.1, stored in `inter/OFL.txt`;
- scripts: Cyrillic, Cyrillic Extended, Latin and others declared by Google Fonts metadata.

The renderer loads these files directly and does not install fonts system-wide.
