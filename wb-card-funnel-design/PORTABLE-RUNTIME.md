# Переносимая среда

Скилл хранит зависимости в собственной папке `.runtime` и не требует прав администратора. При первом использовании запустите из каталога скилла:

```bash
python3 scripts/bootstrap_runtime.py --json
python3 scripts/run_tool.py doctor.py --json --strict-local
```

На Windows вместо `python3` обычно используется `python` или `py -3`. Codex должен сам выбрать найденную команду Python 3.10+.

## Что устанавливается автоматически

- локальное Python-окружение;
- Pillow для точной растровой сборки;
- кириллический Inter и его OFL-лицензия уже находятся в `assets/fonts/inter/`;
- локальный рендерер точного текста, подложек и пользовательских изображений.

Ничего не устанавливается системно и не требует администратора.

## Что нельзя поставить из репозитория

`imagegen`, web/browser и доступы к внешним сервисам являются возможностями Codex и аккаунта. Перед генерацией агент проверяет их наличие в текущей сессии. Если генератора нет, скилл собирает точную инфографику из пользовательских фото и локальных слоёв либо отдаёт проверенный бриф без выдуманного результата.

## Точный локальный рендер

```bash
python3 scripts/run_tool.py render_infographic.py assets/render-spec-template.json --output ./card.png
```

Рендерер работает одинаково на macOS и Windows, использует шрифт из пакета и не зависит от установленной системной типографики.
