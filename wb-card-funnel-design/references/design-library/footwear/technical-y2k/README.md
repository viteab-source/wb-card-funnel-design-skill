# Technical Y2K

Крупная типографика существует как слой пространства, а не как шапка. Подход строится на низком ракурсе, собранной геометрии, одном акценте, контрасте и крупной форме подошвы. Один слайд несёт одну идею.

Использовать для: выразительной обложки, конструкции, подошвы, деталей силуэта. Не использовать для: мелких иконок, псевдотехнологий, агрессивных градиентов и текста, который закрывает обувь.
