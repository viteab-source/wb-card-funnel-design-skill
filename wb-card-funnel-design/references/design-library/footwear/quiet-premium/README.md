# Quiet premium

Свет, материал и пространство работают сильнее текста. Фон спокойный, предмет занимает большую часть кадра, тени правдоподобны, подпись мала и привязана к доказуемому факту.

Использовать для: натурального материала, чистой пары, пятки, макро и обложки с дорогим ощущением. Не использовать для: декоративных плашек, тяжёлых рамок и одинаковой композиции на каждом слайде.
