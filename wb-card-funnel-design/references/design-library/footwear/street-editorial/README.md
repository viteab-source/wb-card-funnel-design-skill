# Street editorial

Товар остаётся резким и крупным в реальной, нейтральной городской среде. Низкая или обычная камера, фактура бетона/архитектуры, спокойный образ и один контрастный акцент допустимы только если не меняют цвет товара.

Использовать для: hero с характером, пары в образе, кадра масштаба. Не использовать для: таблиц, технических claim, постановочной «грязи», дождя или динамики, которые намекают на неподтверждённые свойства.
