# Библиотека визуальных паттернов

Для WB-инфографики приоритет имеет выборка, которую пользователь одобрил в текущем запуске. Публичный пакет не содержит чужие карточки: локальная библиотека создаётся во время исследования и остаётся в артефактах пользователя. Внешние Pinterest/Behance-кандидаты вторичны и используются только если пользователь прямо просит расширить визуальный поиск.

Это не набор шаблонов и не исходники для публикации. Каждый референс используется только как данные о композиции, свете, масштабе товара, типографике и роли кадра. Нельзя переносить в свою карточку фотографию, текст, логотип, узнаваемую композицию или их совокупность.

`patterns.csv` — стартовая выборка. Статус `candidate` означает «собрано для просмотра», а не «одобрено как эталон». После просмотра пользователем референсу присваивается `approved`, `rejected` или `archive`. Только `approved` доступен как основа Visual DNA.

Папки направлений содержат только описания паттернов и ссылки. Чужие изображения в скилл не копируются.

Для компактных beauty-товаров доступен одобренный пользователем паттерн [beauty-performance-approved.md](beauty-performance-approved.md). Используйте его как художественный язык после исследования и выбора hero, а не как готовый шаблон конкретного товара.
