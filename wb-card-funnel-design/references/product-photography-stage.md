# Этап предметной фотосессии

Этот этап обязателен перед созданием инфографики из пользовательских фото. Цель — получить честный набор товарных кадров, из которого затем выбирают карточку, а не заполнять галерею вариациями одного рендера.

## План кадров

Для каждого товара создай `product-shot-plan.md` со строками:

`ID → вопрос покупателя → тип кадра → собственные референсы → что обязано совпасть → статус`.

Базовые роли выбирай, только если они подтверждены исходниками:

- **Пэкшот:** форма, цвет, силуэт; чистый фон, без текста.
- **Доказательный ракурс:** профиль, обратная сторона, дно, верх или открытый вид — только при собственном референсе соответствующей стороны.
- **Макро:** кожа/ткань, шов, застёжка, фурнитура. Не повторяй один фрагмент под разными названиями.
- **Контекст:** применение или масштаб. Он вторичен и не доказывает материал, вместимость, комплектацию или защитные свойства.

Для сумки типичный, но не обязательный список: фас, профиль, три четверти, обратная сторона, верх, дно, открытый вид, макро фурнитуры, макро шва/фактуры, масштаб. Если для пункта нет референса, статус `needs_photo` или `omit`.

## Четыре визуальных блока

Для кожи, техники и других премиальных товаров после пэкшотов можно чередовать:

1. чистую предметку для понимания формы;
2. один атмосферный hero для образа;
3. макро, объясняющее цену через фактуру или качество детали;
4. контекст применения без ложного свойства или комплектации.

Внутри одного блока не выпускай несколько почти одинаковых ракурсов. Один кадр выбирается как лучший, остальные остаются вариантами и не входят в финальную выдачу.

## Приёмка до инфографики

Создай контактный лист. Проверь: точные швы, число молний/отделений, реальную фурнитуру и все маркировки, отсутствие добавленных предметов, различимость ракурсов. Бракуй кадр с подменой товара, даже если он выглядит красивее. На контакте укажи назначение каждого кадра; если назначение совпадает, оставь один сильнейший.

После выбора пользователем предметных кадров накладывай текст отдельно. Никогда не проси генератор одновременно решить предметную точность, рекламную сцену и русский текст, если это можно разделить.
